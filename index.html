⚠️ 文件裡有 SmartArt 圖表（組織圖/流程圖）？點此看處理方式

SmartArt 是向量資料格式，跟一般圖片（.png/.jpg）完全不同，這個瀏覽器端 AI 處理無法自動呈現 SmartArt，轉檔時這些圖表的畫面會被省略（文字內容仍會整理成附錄保留）。想要圖形本身完整還原，改選上方的「精準轉檔 ⚙️」即可，那邊用的是真正的 LibreOffice 引擎，可以正常處理 SmartArt。

如果想在這個 AI 面板裡也保留 SmartArt 圖形本身，請先在 Word 裡手動處理一次：

  1. 在 Word 裡點選該 SmartArt 圖表
  2. 滑鼠右鍵 →「另存為圖片」（或先「複製」，再「選擇性貼上」→「圖片」貼回原本位置，取代原本的 SmartArt）
  3. 存檔後再把這份 .docx 上傳到這裡轉檔，圖片就能正常被讀取

🛠️ 第一次使用？先完成這兩個一次性設定（點此展開步驟）

步驟一：Fork 這個專案到你自己的帳號

在 GitHub 上開啟本專案的頁面，點右上角「Fork」，複製一份到你自己的帳號底下（這一步是一次性的，之後轉檔都用這個 Fork 出來的 repo）。

步驟二：申請一組權限縮小範圍的 Personal Access Token

前往 GitHub 「Settings → Developer settings → Personal access tokens → Fine-grained tokens」，建立新 Token 時：

  • Repository access 選「Only select repositories」，只勾選你剛剛 Fork 出來的那一個
  • Permissions 裡把「Contents」設為「Read and write」，其他權限保持預設（不給）

建立好之後複製那組 Token（只會顯示一次），貼到下方欄位。
