1.Firebase 專案設定與 Flutter 環境準備

(1)到 Firebase 控制台建立專案，並註冊 Android app，下載 google-services.json 放到android/app/下。

(2)Android軟件包名稱必須精確對應Flutter專案的android/app/build.gradle檔案中的applicationId（例如com.example.myapp）

(3)設定 Google services 插件與依賴

位於android/build.gradle.kts 加入，用於全域插件宣告：

plugins {

id("com.google.gms.google-services") version "4.4.4" apply false

}

位於android/app/build.gradle.kts 加入，用於應用特定設定：

plugins {

id("com.android.application")

id("com.google.gms.google-services") // 直接套用

}



dependencies {

implementation(platform("com.google.firebase:firebase-bom:34.8.0"))

implementation("com.google.firebase:firebase-analytics")

}

(4) 開啟 Firebase 控制台啟用 Firestore（資料存儲）與 Authentication（驗證），方便管理用戶與標點資料。

2.安裝 Flutter 相關套件

在 pubspec.yaml 加入：

google_ml_kit: ^0.20.0

firebase_core: ^4.4.0

cloud_firestore: ^6.1.2

firebase_auth: ^6.1.4

http: ^1.6.0 #方便跟後端 API 互動



google_mlkit_text_recognition: ^0.15.0 # 文字辨識
google_mlkit_language_id: ^0.13.1 # 語言偵測
google_mlkit_smart_reply: ^0.13.0 # 智慧過濾
